Playground Atlas Privacy Policy

Effective date: 2026-09-23

Publisher: Nicholas Alan Vandervelden

Information and permissions

Playground Atlas stores no user accounts, location history, or analytics. Its detailed topographic and aerial map layers request public USGS/USDA tiles using coordinates for the visible map area and normal network metadata, including IP address, user-agent/operating-system information, and request time. The map does not send a separate raw GPS field, saved parks, private notes, or typed park searches to USGS. If you use Near Me while online map detail is active, tile requests can reveal an approximate area around your device. The optional Raw OpenStreetMap layer requests public park/playground geometries only while enabled and zoomed in; it sends the visible map bounds (rounded to six decimals), selected feature category, and a 200-feature result limit to the Playground Atlas API hosted in Microsoft Azure's West US 2 region. When Near Me is used, these bounds can also indicate an approximate area. The API request does not include saved parks, private notes, search text, account identity, or a separate raw GPS coordinate. Ordinary network metadata such as the connecting IP and user-agent is visible to the Azure hosting path. No ads or cross-app tracking are used.

Local saved places and notes

Your saved playgrounds, comparison lists, and private notes are stored exclusively in local device storage using standard iOS storage facilities. They are never synchronized to external servers or accessible to third parties. You can export your saved places via native iOS sharing or delete them at any time directly within the app.

Services and external links

Online topographic tiles are requested directly from USGS The National Map; aerial tiles are requested from USGS/USDA NAIP services. USGS says its system logs record IP address, browser/OS, access time, and requested pages/information for internal site management; the published notice does not specify a retention period (https://www.usgs.gov/office-of-the-director/privacy-policies). The optional OpenStreetMap layer is served by the read-only Playground Atlas API hosted in Microsoft Azure in West US 2. It returns raw OSM geometries under ODbL-1.0; these are distinct from the 426 curated destinations and are not verified amenity, safety, or accessibility claims. PlayScout's API does not log user viewport requests, and the Nginx access log is disabled; Azure platform processing of standard connection/operational metadata remains subject to Microsoft's policies, and a specific Azure platform retention period has not been established. Requests use HTTPS GET without cookies or credentials. Other park-source and directions links open outside the app in Safari or Maps.

Retention and choices

Saved parks, comparison lists, and private notes remain in local device storage and are deleted when the app is removed. The PlayScout API does not persist viewport request URLs or client IPs in application access logs; Nginx access logging is disabled. Azure infrastructure may process standard network/operational metadata under Microsoft's service policies. The developer has not established a fixed retention period for any Azure platform metadata and does not promise a specific deletion interval. USGS processes its system logs under its published privacy notice, which does not state a specific retention period.
